## Timing Object

This repository contains the [Timing Object](https://webtiming.github.io/timingobject/) specification, developed in the [W3C Multi-Device Timing Community Group](https://www.w3.org/community/webtiming/).

**Work on the specification has been discontinued** and the Community Group was closed early 2025. The specification is provided as-is in the hope that it may prove a useful basis for renewed discussions on a timing model for the Web in the future. Interested parties are encouraged to reach out to the [Media and Entertainment Interest Group](https://www.w3.org/groups/ig/me) for coordination, through its [public-web-and-tv@w3.org](mailto:public-web-and-tv@w3.org) mailing-list.
